# Fahrtenbuch Bot — Demo Guide

Цей документ допомагає швидко показати продукт замовнику: що підготовлено, як запустити бота, які сценарії натискати в Telegram і які обмеження варто чесно проговорити.

## 1. Статус готовності

- Бот запускається локально у polling-режимі.
- SQLite база створена: `fahrtenbuch.db`.
- Міграційний статус локальної БД: `0009_user_account_roles`.
- Автоматичні тести проходять: `93 passed`.
- Callback-кнопки перевірені: `120` кнопок, `0` без handler-а.
- Експорти перевірені: CSV, ZIP, Fahrtenbuch PDF, EÜR PDF, PNG-графіки.
- Багатокористувацький режим увімкнений через `user_accounts`.
- Додано audit log, dashboard, open tasks, smart address rules, Steuerberater package, roles owner/driver.

## 3. Demo Flow у Telegram

### Реєстрація

1. Надіслати `/start`.
2. Якщо профіль вже існує — ввести 6-значний PIN.
3. Якщо це перший вхід — ввести ім'я.
4. Обрати мову.
5. Переконатися, що відкрився головний menu keyboard.
6. Зберегти PIN, який бот показує після реєстрації.

### Відновлення профілю через PIN

1. Відкрити бота з іншого Telegram-акаунта.
2. Надіслати `/start`.
3. Ввести 6-значний PIN.
4. Переконатися, що відкрився той самий профіль і підтягнулись дані.
5. Перевірити, що перший Telegram-акаунт також лишився прив'язаним до профілю.
6. Для створення нового PIN використати `/my_pin`.

### Багатокористувацький режим

1. Зареєструвати користувача A і додати авто/поїздку.
2. Зареєструвати користувача B з іншого Telegram-акаунта.
3. Переконатися, що користувач B не бачить авто/поїздки користувача A.
4. Ввести PIN користувача A з третього Telegram-акаунта.
5. Переконатися, що третій Telegram бачить дані A, але не бачить дані B.

### Контроль якості даних

1. `/dashboard` — показати підсумок місяця.
2. `/open` — показати відкриті задачі перед звітом.
3. `/audit` — показати Änderungsprotokoll.
4. `/team` — показати ролі owner/driver.

### Smart address rules

1. Додати адресу з назвою, наприклад `Büro Mitte`.
2. Створити поїздку.
3. У ручному вводі адреси написати `mitte` або `Büro Mitte`.
4. Переконатися, що бот розпізнав адресу і прив'язав її до поїздки.

### Автомобілі

1. Натиснути `🚗 Мої авто` або команду `/cars`.
2. Натиснути `➕ Додати авто`.
3. Ввести марку, модель, номер, пробіг.
4. Відкрити авто зі списку.
5. Перевірити кнопки:
   - `✏️ Редагувати пробіг`
   - `🗑 Видалити`
   - `◀️ Назад`

### Адреси

1. Натиснути `📍 Адреси` або `/addresses`.
2. Натиснути `➕ Додати адресу`.
3. Ввести назву, адресу, тип.
4. Відкрити адресу зі списку.
5. Перевірити кнопки:
   - `🏠 Зробити домашньою`
   - `✏️ Редагувати`
   - `🗑 Видалити`
   - `◀️ Назад`

### Поїздки

1. Натиснути `📋 Поїздки` або `/trips`.
2. Натиснути `➕ Нова поїздка` або команду `/newtrip`.
3. Обрати авто.
4. Обрати стартову адресу або ручний ввід.
5. Обрати кінцеву адресу або ручний ввід.
6. Ввести стартовий і кінцевий пробіг.
7. Обрати мету: business/private.
8. Відкрити створену поїздку.
9. Перевірити кнопки:
   - `✏️ Редагувати`
   - `🗑 Видалити`
   - `🔍 Фільтр`
   - `📋 Всі поїздки`

### Чеки та витрати

1. Натиснути `🧾 Чеки та витрати` або `/receipts`.
2. Натиснути `➕ Додати вручну` або команду `/newreceipt`.
3. Ввести дату, суму, vendor, опис, категорію, VAT.
4. Відкрити чек зі списку.
5. Перевірити кнопки:
   - `✏️ Редагувати`
   - `🏷 Змінити категорію`
   - `🗑 Видалити`
   - `🔍 Фільтр`
   - `📊 Статистика`

### Доходи

1. Викликати `/addincome`.
2. Ввести дату, суму, клієнта, invoice number, VAT.
3. Відкрити список доходів через меню/команди, якщо доступно.
4. Перевірити статистику по місяцях і видалення доходу.

### Звіти

1. `/report` — Fahrtenbuch PDF.
2. `/taxreport` — EÜR PDF.
3. `/export` — CSV/ZIP для бухгалтерії.
4. `/steuerpaket` — повний ZIP для Steuerberater за поточний рік.
5. `/stats` — графіки пробігу.

## 4. Зовнішні залежності

- Telegram polling потребує доступу до `api.telegram.org`.
- OCR фото чеків потребує `ANTHROPIC_API_KEY`.
- Геокодинг без `GOOGLE_MAPS_API_KEY` працює через OpenStreetMap/Nominatim і може бути rate-limited.
- Для production бажано PostgreSQL через `DATABASE_URL`.

## 5. Важлива безпека

Токен бота був вставлений локально в `.env`. Після демо краще перевипустити токен у BotFather і замінити його в `.env`.

## 6. Telegram Storage Bot

Для демонстрації backup storage можна підключити другого Telegram-бота:

```env
ADMIN_TELEGRAM_ID=your_telegram_user_id
STORAGE_BOT_TOKEN=storage_bot_token_from_botfather
STORAGE_CHAT_ID=-1001234567890
```

Команди:

- `/storage_status` — перевірка, чи налаштований storage.
- `/storage_backup` — відправляє SQLite backup у приватний storage-чат/канал через другого бота.

Важливо: другий Telegram-бот не є SQL-базою. Це backup/mirror storage. Основна робоча БД лишається SQLite або PostgreSQL.
